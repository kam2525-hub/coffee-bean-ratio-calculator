# ハンドドリップ珈琲・粉量と抽出比率の逆算シミュレーター

淹れたい杯数やマグカップの容量から、必要なコーヒー豆のグラム数と最適な湯量を一発で算出するツール

## 🌟 主な特徴
- **完全フロントエンド完結**: サーバー不要でブラウザを開くだけで即座に動作。
- **安心・安全**: データはブラウザのローカル環境のみで処理され、外部への通信は行いません。
- **モバイル対応**: スマートフォン・PCのどちらでも直感的に使えるレスポンシブ設計。

## 🚀 使い方
1. リポジトリ内の `index.html` をブラウザで開きます（または GitHub Pages でアクセス: https://kam2525-hub.github.io/coffee-bean-ratio-calculator/）。
2. 画面の指示に従って操作します。
